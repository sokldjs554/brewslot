argument-hint: <결정 제목>
---

`docs/adr/` 의 마지막 번호 + 1 로 "$ARGUMENTS" ADR 을 작성하고 `docs/adr/README.md` 표에 추가한다.

- **맥락**: 어떤 문제/제약 때문에 결정이 필요한가 (수치가 있으면 수치)
- **결정**: 무엇을 하기로 했는가. 코드 위치 링크
- **대안**: 최소 2개, 각각 왜 기각했는가 (표)
- **결과**: 얻는 것(+) / 잃는 것(−) / 언제 재검토하는가 / 어떤 테스트·측정으로 검증하는가

과장하지 않는다. 측정하지 않은 성능 주장은 쓰지 않는다.
